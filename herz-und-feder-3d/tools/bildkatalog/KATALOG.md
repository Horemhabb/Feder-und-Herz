# Bildkataloge

Jeder Eintrag hat einen fertigen Prompt (Englisch, für die Bild-KI). Das Zuschneiden, der Goldrahmen, das Klassenband und die graue Sperre kommen danach aus dem eigenen Werkzeug, nicht von der KI: So bleibt der Satz einheitlich.

## Stilbibel (steht in jedem Prompt)

> Ancient Egyptian painted-relief style game icon, single centered motif filling about 75% of the frame, bold clean silhouette that stays readable at 64 pixels, flat saturated tomb-painting colors (Egyptian blue, malachite green, ochre, carnelian red, ivory) with thin black outlines, small gold-leaf accents, subtle warm glow behind the motif, plain dark sandstone background, no text, no border, no frame, square

Regeln: immer ein Motiv, nie Text, nie Rahmen; immer dasselbe Referenzbild mitgeben, sobald eine Vorlage gewählt ist; Quadrat; danach auf 64 Pixel verkleinern und prüfen, ob man es noch erkennt.
